# Accessible Portfolio Skeleton

A multi-page personal portfolio website built with semantic HTML5, accessible navigation, SEO-friendly metadata, and a keyboard-friendly contact form.

## Pages

- `index.html` - home page and introduction
- `about.html` - profile, values, and skills
- `projects.html` - project showcase
- `contact.html` - accessible inquiry form

## Accessibility Features

- Semantic landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Skip link for keyboard and screen reader users
- Page-specific `h1` headings and logical heading hierarchy
- `aria-current` for active navigation states
- Descriptive `aria-label` values for navigation and contextual links
- Persistent labels, hints, errors, and live status messaging in the contact form
- Visible focus styles and reduced-motion support
- Responsive layout with readable contrast

## SEO Features

- Unique page titles and descriptions
- Canonical URLs
- Open Graph and Twitter card metadata
- Crawlable text content and descriptive image alt text

## How to Run

Open `index.html` directly in a browser, or serve the folder with any static web server.
